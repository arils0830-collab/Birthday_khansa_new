# BIRTHDAY KHANSA 🤍

## Cara menjalankan
1. Extract folder ZIP.
2. Buka file `index.html`.
3. Website akan terbuka di browser.

## Password
Password default:
khansa

Untuk mengganti password, buka `script.js` lalu ubah:
const PASSWORD = "khansa";

## Menambahkan musik
Masukkan file musik MP3 ke folder utama dengan nama:
music.mp3

Contoh:
Birthday-Khansa/
├── index.html
├── style.css
├── script.js
├── music.mp3
└── images/

Lalu tombol musik di pojok kanan bawah bisa digunakan.

## Catatan
Website dibuat khusus tampilan HP/portrait dan tetap responsif di desktop.

## Mode foto cinematic
Foto sekarang ditampilkan sebagai cinematic slideshow dengan zoom perlahan, vignette, caption, navigasi swipe, panah, dots, dan auto-play setiap 7 detik.
